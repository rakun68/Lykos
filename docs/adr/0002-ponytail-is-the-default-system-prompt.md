# The ponytail ruleset is the default system-prompt content

Every Lykos session boots with the ponytail minimalism ladder in its system prompt, and a preset may
replace it. This reverses an earlier decision that rejected ponytail, and the reversal turns on the
delivery mechanism rather than on a change of taste: the independent 251-trial test that the earlier
rejection cited did measure a real effect — around ten per cent lower cost at p=0.004 with no
quality difference — but found the skill **never self-activated when installed passively**. The
effect appeared only when the ruleset was force-injected into the prompt, which is exactly what a
preset's instructions field does.

## Consequences

The exact text must be taken from the ponytail project at implementation time and attributed with
its MIT licence. Paraphrasing it from memory would discard the only thing the evidence is about.

The existing response-verbosity head block covers a different subject — how much the agent says,
rather than how much it builds — so both blocks stay, and any sentence that would appear in both is
removed from one of them.

## Status

Supersedes the 2026-08-30 decision recorded in the pre-reorganisation decision log, which rejected
ponytail as a passively installed skill.
